# Decisões arquiteturais

Este diretório contém os Registros de Decisão Arquitetural do `go-cnpj-loader`.

## Convenção

Os arquivos seguem numeração sequencial, como `0001-titulo-da-decisao.md` e `0002-outra-decisao.md`.

Cada ADR possui um dos seguintes estados:

- `proposed`: decisão ainda em avaliação;
- `accepted`: decisão adotada;
- `superseded`: decisão substituída por outro ADR;
- `deprecated`: decisão que deixou de ser aplicável.

Os estados são valores internos e permanecem em inglês. O conteúdo dos documentos é escrito em português.
